- Cloudflare 계정 인증·실제 웹 배포·상시 연결의 권한 승인과 연속 수신은 위 추가 검증에서 완료했다.

## 확인한 복구와 상태

- 검색·필터·계정 범위를 보존하고 전역 재고/일정에서는 계정 범위를 해제한다. 실패 예약은 사유 확인→새 예약→기존 기록 보존·닫기까지 실행했다.
- 지시 접수·원본 설정 반영·그 뒤 관측을 구별한다. 합쳐진 지시의 요청 ID도 보존하며, 오래 대기한 지시가 최신 종료 기록에 밀려 사라지지 않는다.
- 스냅샷 본문/청크의 시점을 맞추고 파손 뒤 정상 스냅샷으로 회복한다. 미리보기는 유한 재시도·실패 표시·명시적 재시도를 갖추며 앞선 실패가 뒤 그림을 막지 않는다.
- 실행 잠금은 ‘실행 감지’로 표현한다. 단계별 heartbeat가 없는 원본의 특성을 반영해 오래된 실행을 ‘진행 확인 필요’로 표시하며, 실행 성공·진행 중단을 단정하지 않는다.
- 3D 파일 실패 시 계정 목록과 업무 패널이 유지된다. JS 반복 실패와 CSS 실패 뒤 재시도가 Chromium/WebKit 모두 통과했다. World와 Three를 하나의 지연 로딩 파일로 묶고 실패한 모듈 URL을 재사용하지 않는다.
- 새 빌드의 manifest를 받으면 기존 앱과 혼합하지 않고 새 문서로 이동한다. 버전 검사 2개 독립 사례와 브라우저의 manifest 변경 분기를 확인했다. 실제 서버에서 서로 다른 두 빌드를 교체하는 배포 시험은 하지 않았다.
- GLB 부분 실패·응답 지연·WebGL context loss/restore·입력 취소·확대·회전 투영을 별도 기술 재심에서 확인했다. 3D를 사용할 수 없어도 계정과 일정 관리 경로가 남는다.

## 게임 장면의 근거

제작 라인·검수 게이트·목표 비축랙·출하 도크를 계정 작업동과 구별했다. 게임과 UI 심사자가 글자를 숨긴 3개 화면 크기와 일반 화면 3개를 직접 확인했다. 실제 공정 mesh 4/4의 목적지, 작업/정지/오래된 상태/동작 줄이기 4종의 구별, 전체 비축 0/1560/3900에서 0/4/10칸을 확인했다. 계정별 0/120/300도 0/4/10칸이다.

게임 전문가의 최초 독립 실행은 자동 14/15 통과이며, 단발 타이밍으로 실패한 대기 표시 1개는 직후 동일 장면의 캡처로 확인했다. 이를 자동 15/15 통과로 바꾸지 않는다. 추가 지적 R1/R2는 수정 후 2/2 수용됐다. [게임 보고서](reviews/recheck-game.md), [사용자 관점 보고서](reviews/recheck-customer.md)에 승인 범위가 있다.

## 데이터 보호와 남은 범위

화면 시험의 일정·지시는 격리 메모리 DB에서 실행했다. 원본 자동화를 시험 목적으로 정지하거나 제출·재확인 지시를 보내지 않았다. 실데이터 확인은 읽기 전용 스냅샷과 미리보기를 사용했다. 13개 계정의 제출 가능 집계를 원본 keyword_allocation.ready_count와 대조했으며 운영 중 수량은 계속 변한다.

실제 휴대전화·태블릿의 GPU·발열·배터리·장시간 메모리, 실제 플랫폼 제출 성공, 며칠 이상 반복 사용과 재방문 재미는 미측정이다. 전문가의 범위별 승인은 상용 대작과의 절대 동급 또는 사용자 만족도 보증이 아니다. 제출 제외 사유 중 일부는 원본 계약에 개별 코드가 없어 배정·중복·대기 사유를 묶어 안내한다.

10월 18일에는 HTTPS·로그인·외부 접속과 상시 연결 서비스가 미적용이었다. 10월 21일 실제 배포와 상시 연결 완료 근거는 문서 첫 부분을 따른다. 운영 절차는 [배포 안내](DEPLOY.md)에 있다. 다른 사업은 등록과 미연결 표시까지 지원하며 실제 데이터 연동은 후속 작업이다.

## 이전 기록의 적용 범위

artifacts/verification/cloudflare-runtime.json은 초기 구현 당시 Cloudflare **로컬** 엔진·D1·인증·정적 파일의 확인 기록이다. 최신 수정본의 원격 배포 증거가 아니다. performance.json의 모델 24개·90 draw calls·headless FPS는 초기 장면 수치이며 현재 장면 성능으로 인용하지 않는다. 마지막 시설 보완과 재질 통합은 최종 통합 시험에서 렌더됐지만 실기기 성능 시험으로 대체되지 않는다.

최종 읽기 전용 smoke에서 PC 104·모바일 106 draw calls, 약 10.3만 삼각형을 관측했다. 동작 줄이기 모드의 자원 수치이며 실기기 FPS가 아니다. 같은 실행의 final-desktop.png·final-mobile.png와 final-smoke.json을 artifacts/verification에 보관했다.
