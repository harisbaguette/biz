# BLUEKITE WORKS 프런트엔드

세로 모바일에서 전체 화면의 Three.js 제작소가 첫 화면이다. 13개 계정의 현재 심사, 결과 예상일 또는 막힌 원인, 확인·재시도 시각을 기본 전경에 함께 보여 준다. 공유 제작기와 계정별 출고 묶음·심사함·완료 보관, 월 수익 장부가 한 공간에 있다. 계정 선택은 해당 작업대를 확대하고 금속 행동판을 열며, 닫으면 13계정 전경으로 돌아온다.

## 디자인 시스템

정본은 사용자가 지정한 `/Volumes/public/디자인시스템/실행관리(Ops-Run)`의 Pattove **main 0.8.0 / Trial**이다. 공식 React 부품·CSS·Pretendard/Outfit·민트 세라믹 아이콘을 실제로 가져온다. 이전 Inkpress/Lucide 화면을 대체했다.

```sh
npm run design:sync
npm run design:check
```

원본 위치는 `PATTOVE_DESIGN_SYSTEM`으로 바꿀 수 있다. 원본이 없는 환경에서도 Git에 포함된 파일로 빌드할 수 있다. `src/design-system/vendor/manifest.json`에 정본 91개 파일의 SHA-256을 기록한다. 원본 파일을 직접 수정하지 않는다. [적용 방법](../src/design-system/README.md) · [출처](../src/design-system/ASSETS.md)

상단 연결·문제 표시와 하단 게임 콘솔·행동판은 `src/App.tsx`와 `src/style.css`, 상세 창은 `src/ui/Panels`·`Management`·`Finance`, 월드·표식은 `src/world`가 맡는다. 공식 `Button`, `IconButton`, `Input`, `Select`, `Switch`를 재사용하고 소비층에서 금속 명판·인레이·금고 형태로 마감한다. `--p-*` 토큰과 rem 글자 크기를 유지한다.

## 세계와 조작

- 기본 전경: 13계정 동시 조망. 계정 번호와 순서는 유지하며 화면 비율에 맞게 단지를 배치한다.
- 시설 선택: 실제 작업대·시계·그림 묶음이나 최소 44px 명판을 누른다. 명판에는 심사·결과 예상 또는 막힌 원인·다음 시각을 상시 표시한다. 한 손가락으로 이동하고 두 손가락으로 확대한다. 회전은 잠근다.
- 빈 땅 또는 닫기를 누르면 전체 보기로 돌아온다. 하단의 다음 일정·제출·심사 이력·자동화 설정은 실제 행동을 이름 붙인다.
- 상세 창이 열리면 배경 입력을 막고 키보드 초점을 창 안에서 순환한다. 닫으면 열었던 조작부로 돌아온다.
- WebGL 또는 모델 로딩 실패에는 목록·재시도 경로가 남는다. 탭이 숨겨지거나 세계가 정지해 있을 때 불필요한 렌더를 멈춘다.

공유 제작기와 짧은 롤러 운반대, 황색 심사함, 자체 제작한 인쇄물·제출철·시계·완료 포트폴리오를 사용한다. 아스팔트 도로와 멀리 분리된 긴 심사·공개 선반은 제거했다. 실제 적용·출처는 [ASSETS.md](../ASSETS.md)를 따른다. 앱 아이덴티티는 [BLUEKITE WORKS 브랜드](BRAND.md)다.

자원 수량·적재·문제·작업 상태는 실제 스냅샷에서 읽는다. 명령 접수와 실제 수행 성공을 구별한다. 연결이 오래되면 새 지시를 막으며, 낮은 재고를 오류로 표시하거나 허구의 코인·성공·물류를 만들지 않는다.

`operations-state.ts`가 현재 고유 작품을 집계하고 `owner-cycle.ts`가 현재 심사·결과 예상 또는 막힌 원인·다음 시각·오류 원인을 독립적으로 계산한다. 출고는 ready, 심사는 submitted, 완료 보관은 approved/published다. 플랫폼 심사 수와 추적 수가 다르면 대조 필요를 표시한다. 정확한 원본 오류를 서로 다른 원인으로 안내하며, 자료가 오래되면 확정 일정을 숨긴다. `game-state.ts`는 제작기 가동과 지시 후 실제 확인 여부를 판정한다. 수익은 `finance-types.ts`의 별도 원장으로 전하며 조회 오류가 작업기 전체 상태를 바꾸지 않는다. Finance에서 고친 월 기록은 세계 장부에도 즉시 반영한다.

## 검증

브라우저 검증은 격리된 데이터와 headless Chromium·WebKit에서 한다. 운영 자동화를 켜거나 실제 제출을 실행해서 시험하지 않는다. 실데이터 캡처·인증 파일·개인 진행 지도는 Git에 포함하지 않는다. 실기기의 발열·배터리와 장기 몰입도는 브라우저 검증만으로 확인할 수 없다.
