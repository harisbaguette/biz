# BLUEKITE WORKS 사업 게임

혼자 운영하는 여러 사업을 한 공간에서 보고 다음 지시를 내린다. 첫 사업은 실제 운영 중인 미리캔버스 기여자 13계정이다. 계정의 제작, 사용 가능한 비축, 실제 제출, 심사 결과를 구분한다. 허위 성공 수치와 가짜 운영 움직임은 만들지 않는다.

## 화면

현재 구현 기준은 [세로 모바일 게임 설계](mobile-game-direction.md)와 [프런트엔드 구조](FRONTEND.md)다.

세로 모바일의 전체 화면 Three.js 세계에서 시작한다. 13계정을 아틀리에·작업실·물류·항구 네 지구에 나누고, 건물을 누르면 카메라가 다가가며 현장 행동이 나타난다. 상단에는 실제 제출 가능 재고·심사 중·확인할 일만 둔다. 재고 상자와 작업 신호는 실제 관측에 따라 바뀐다.

한 손가락으로 이동, 두 손가락으로 확대·축소한다. 모바일 회전은 잠그고 지구 이동·현재 지구 복귀 버튼을 제공한다. 선택 시설은 HUD와 트레이 사이에 유지한다. 태블릿과 PC에서는 넓어진 세계와 상세 창을 함께 사용한다. 긴 목록과 입력은 재고·일정·운영실의 상세 도구에 둔다. WebGL 실패 시에도 계정 목록을 통해 실제 업무에 접근한다.

## 실제 연결

맥미니의 PostgreSQL `miricanvas_upload`를 읽기 전용으로 조회한다. 전체 PNG를 검사하는 기존 `/api/state`는 30초에 응답하지 않아 주기 조회로 사용하지 않는다. 현재 운영 정책의 `production_stock.inventory`로 목표와 공정을 읽고, `keyword_allocation.ready_count`의 제목·후보 소유권, 재시도 시각, 기제출 제외, 대표어 중복 제외 조건을 적용해 실제 제출 가능 재고를 계산한다. API 스냅샷에는 계정, 단계별 수량, 제출 이력, 일정, 작업기 상태만 허용 목록으로 복사하고 DB 접속 정보·경로·인증 정보는 보내지 않는다.

관제 자체 일정·지시는 별도 저장하며 결과를 기록한다. 원본 자동화의 설정과 연결하는 명령은 지원되는 필드만 바꾸고 기존 운영의 중복 제출 방지를 유지한다. 실데이터와 연결이 끊기면 마지막 관측 시각과 연결 끊김을 명확히 표시한다. 다른 사업은 미연결로 표시하며 사업 등록과 상태 관리가 가능하다.

- 사용자 참고: https://x.com/DilumSanjaya/status/2106426962738880879 — 창고 직접 선택, 3D 시설과 실제 운영의 결합. 게시글과 영상 섬네일을 직접 확인했다. 영상 파일은 확보했으나 전체 재생은 검증하지 않았다.
- Cities: Skylines II: https://www.paradoxinteractive.com/games/cities-skylines-ii/features — 세계를 중심에 두고 선택한 객체의 정보와 조작만 노출한다.
- shapez 2: https://shapez2.com/ — 생산 흐름과 정체 지점을 공간에서 읽는다.
- 세로 모바일 기준작: Egg, Inc.·Pocket City 2·Tiny Tower. 공식 화면 비교와 선택 근거는 [게임 설계](mobile-game-direction.md)에 있다.
- KayKit City Builder Bits의 건물·차량·가로 시설과 같은 제작자의 조경·재고 소품. 실제 파일·가공·라이선스는 [ASSETS.md](../ASSETS.md)에 기록한다.
- 지정 `/Volumes/public/디자인시스템/실행관리(Ops-Run)`의 Pattove main 0.8.0 Trial. 정본 컴포넌트·아이콘·Pretendard/Outfit 폰트를 사용한다. BLUEKITE WORKS 로고·파비콘·앱 아이콘은 [브랜드 안내](BRAND.md)를 따른다.

## 검증

390×844, 768×1024, 1440×900, 900×1440, 가로 모바일, 키보드·200% 확대를 headless로 확인한다. 생성기 원본은 읽기 전용으로 대조하며 지시의 변경 시험은 임시 원본에서 한다. 일정 저장·재진입·취소, 잘못된 입력, 세션·권한, 연결 끊김, WebGL 실패, 3D 선택과 프레임을 확인한다.
