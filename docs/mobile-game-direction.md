# 세로 모바일 사업 경영게임 설계

2026-10-22 · 설계 범위: 현재 미리캔버스 13계정과 실제 연결된 제작·검수·재고·제출·일정·운영 기록. 기준 화면 390×844, 하한 360×640.

## 게이머 관점의 기존판 거부 이유

기존 모바일 실물 `artifacts/followup/labels-world-360-740.png`를 기준으로 판정했다.

1. 건물을 누르면 세계가 비활성화되고 별도 업무 패널로 넘어간다. 세계 안에서 지시하고 결과를 보는 경험이 끊긴다. 3D는 시설 목록의 썸네일 역할에 머문다.
2. 17개 표찰을 한 화면에 욱여넣으면서 건물의 형태·작업의 움직임·구역의 성격이 사라졌다. 번호를 읽어야 찾을 수 있으면 공간 기억을 쓰는 게임의 이점이 없다.
3. 상단 제목·경고·도구, 하단 요약·메뉴가 세계를 압박한다. 360×740 실물에서 건물 하나가 엄지보다 작다. 확대와 회전 조작을 메뉴에서 찾아야 하니 시작부터 조종법과 싸운다.
4. 단색 공장 반복과 회색 빈 바탕은 임시 레벨의 인상을 준다. 팩을 구매하거나 모델 수를 늘려도 조명·도로·소품·건물 크기·카메라가 한 장면으로 편집되지 않으면 해결되지 않는다.
5. 모든 곳이 같은 상태 표찰이면 '어느 생산선을 먼저 살릴지' 결정할 이유가 약하다. 실제 병목과 다음 일의 위치가 세계에서 드러나야 한다.

## 결정한 방향

**한 손으로 내 창작 산업단지를 돌아보고, 막힌 생산선을 풀고, 다음 출하를 준비하는 세로 경영게임.**

첫 화면부터 화면 전체에 Three.js 세계를 그린다. 메뉴를 열어도 선택 시설은 세계에 남는다. 제작·검수·비축·출하라는 실제 업무 동사를 공간과 짧은 현장 명령으로 실행한다. '게임처럼 보이는 웹 대시보드'라는 인상을 없애는 기준은 건물 모양이 아니라 **대상 선택 → 카메라 접근 → 현장 지시 → 세계 상태 변화**가 이어지는가다.

상시 항목은 상단 HUD 1줄과 하단 지구 탐색 하나다. 계정·재고·일정·경고·설정을 모두 탭바로 늘어놓지 않는다. 공정 시설은 실제 월드에서 선택하고, 원격 설정·운영 기록은 본부의 상세로 둔다. 상세 데이터에 접근하는 길은 보존한다.

단지 보기에서 13개 계정 표찰을 상시 노출하지 않는다. 네 지구 상태와 공정 병목만 보인다. 가까운 지구에서 해당 3–4개 시설만 표찰을 켠다. 전체 현황은 읽을 표찰 개수가 아니라 **막힘이 있는 지구와 흐름이 멈춘 공정**으로 파악한다.

## 플레이 루프 3층

| 층 | 행동과 결정 | 실제 보상 |
|---|---|---|
| 초 단위 | 경고 지구 선택 → 멈춘 시설 확인 → 원인에 맞는 한 가지 지시 또는 상세 확인 | 선택·접수의 즉각 피드백, 실제 반영 시 시설 상태 복구 |
| 한 방문 1–3분 | 오늘의 병목 한 곳 해소, 제출 가능한 재고와 다음 일정 점검 | 확인된 문제 감소·제출 준비 수량·다음 작업 확정. 임의 경험치 없음 |
| 여러 방문 | 계정별 생산선과 제출 일정 조정, 실제 운영 기록과 결과 축적 | 이전 방문 이후 확인된 변화, 실제 사업별 확장. 없는 사업은 잠금 해금 연출로 부풀리지 않음 |

실행할 일이 없는 날은 안정된 세계와 다음 실제 예정 시각이 끝이다. 사용자를 머무르게 하려고 무의미한 클릭이나 가짜 긴급 임무를 만들지 않는다.

## 경제와 자원

사업 상태의 단위와 관측 시각을 그대로 쓴다. 기존 데이터에 없는 분당 유입·유출을 추정해 HUD에 표시하지 않는다.

| 자원 | Source / Sink | 방문당·분당 유입과 유출 | 쌓이기만 할 때 |
|---|---|---|---|
| 제출 가능 재고 | 실제 제작·검수 완료 / 실제 제출 이력 반영 | 직전·현재 성공 스냅샷 차이에서만 산출. 이력이 없으면 `미측정` | 재고 증가 지구를 알려 제출 일정 확인으로 연결. 임의 폐기 없음 |
| 심사 중 | 실제 제출 확인 / 실제 심사 결과 | 확인된 상태 변경으로만 측정 | 오래된 건은 마지막 관측 시각과 상세 확인. 임의 완료 없음 |
| 예정 작업 | 사용자가 저장한 실제 일정 / 실행·취소·변경 기록 | 저장·실행 이력 건수 | 과거 일정이 남으면 확인할 일. 성공으로 자동 처리하지 않음 |
| 운영 문제 | 실제 오류·실패·미수신 / 확인된 복구·해결 기록 | 실제 발생·해결 건수 | 실패 원인과 재시도·상세로 연결. 읽었다고 해결되지 않음 |

클릭 수, 접속 시간, 카메라 이동으로 돈·생산량·작업 완료를 주지 않는다. 지시 응답 200은 접수일 수 있다. 실행 중·성공·실패·관측 불명 상태를 따로 유지한다.

## 첫 30초

0–3초: 타이틀 설명 없이 세계가 열린다. 실제 확인할 일이 있으면 그 지구에 한 개의 형태 있는 경고 표식. 없으면 선택 가능한 가까운 지구를 보여준다.

3–8초: 지구를 누르면 부드럽게 접근한다. 이름표보다 건물이 커져 손가락으로 잡을 수 있는 대상이 된다.

8–15초: 건물을 누르면 선택 링과 트레이. 원인과 가능한 다음 행동 한 개가 보인다. 잘못 선택했다면 빈 땅 터치 한 번으로 되돌린다.

15–22초: 상태를 확인하거나 실제 지시. 실제 지시는 대상·동작·영향이 담긴 기존 확인 절차를 보존한다. 접수 뒤 윤곽 표식과 짧은 `접수됨`만 나타난다.

22–30초: 실행 증거가 도착하면 상태가 바뀌고 한 번만 결과 피드백. 도착하지 않았으면 대기를 유지한다. 다른 시설을 선택해도 작업 상태가 사라지지 않는다.

## 조작과 접근성

| 입력 | 이동 | 선택 | 확대 | 복귀 |
|---|---|---|---|---|
| 세로 터치 | 한 손 드래그 팬, 하단 지구 탭 | 탭, 드래그 종료 후 선택 금지 | 두 손가락 핀치, 선택 시 자동 접근 | 하단 원점 48px, 빈 땅 탭은 선택만 해제 |
| 마우스 | 드래그 팬 | 클릭 | 휠 | 홈 버튼 |
| 키보드 | 지구 버튼 Tab·Enter | 건물의 대응 접근 가능한 버튼 | 확대·축소 버튼 Tab·Enter | Escape로 트레이 닫기, 현재 지구 보기 버튼으로 복귀 |

모바일 회전은 기본 잠금. 세로 사용자에게 3D 조종을 과제로 주지 않는다. PC는 넓어진 세계에 지구를 함께 보여도 같은 게임 흐름을 유지한다. 가로 전환 때 월드 인스턴스·명령·선택이 초기화되지 않는다. 운영 상세가 길면 트레이 내부를 스크롤하며 세계 팬과 충돌하지 않는다.

색 외에 정상·대기·문제를 원형/점선/느낌표로 구분하고 접근 가능한 이름을 둔다. 소리를 꺼도 모든 신호가 보인다. 모션 줄이기에서는 카메라 이동은 즉시 전환하고 파티클·지속 움직임을 제거한다.

## 아트 디렉션

컨셉: **작은 크리에이티브 산업도시를 엄지로 운영한다.**

- 정교한: 건물의 문·창·적재 구역·도로 경계를 충분히 크게 보여 실제 작업 장소라는 인상을 만든다.
- 명료한: 지구마다 재료색과 실루엣을 구분하고 HUD는 사용자 지정 디자인 시스템의 토큰·아이콘·컴포넌트를 따른다.
- 살아 있는: 실제 실행 중인 공정에만 짧고 국소적인 움직임을 주고, 성공 수신에만 작업물의 위치가 바뀐다.
- 기준작: Egg, Inc.의 큰 세로 입체세계와 Pocket City 2의 연속된 공간·거리감.
- 시점: 고정 방위의 등각에 가까운 사선 직교투영. 가까운 지구의 계정 건물 폭 72–112 CSS px, 터치 영역 최소44px. 390px에서 3–4개 작업동이 우선이다.
- 팔레트: HUD는 `/Volumes/public/디자인시스템/실행관리(Ops-Run)`의 Pattove `main` 0.8.0 Trial 토큰·컴포넌트·아이콘 정본을 사용한다. 세계는 [endesga-32](https://lospec.com/palette-list/endesga-32)의 청색·녹색·중성 축을 참고하되 승인 DS 토큰에 매핑하고 별도 랜덤 색을 늘리지 않는다.
- 윤곽·빛: 검은 외곽선 효과 없이 실제 메시에 의한 윤곽, 일관된 한 방향 주광·부드러운 접지 그림자. 작은 화면에서 흰 지붕이 날아가지 않게 한다.
- 오디오: 기본 무음, 선택 가능한 짧은 UI음만. 자동 BGM·지속 공장 소음 없음.
- 금지: 같은 박스 공장13개, 회색 빈 평면, 모든 창문 점멸, 거짓 운송 흐름, 과도한 안개·블룸, 17개 상시 표찰, 웹 페이지 제목 영역, 업무와 무관한 장식 미니게임.

## 플레이테스트 가설과 강한 반려 기준

1. 390×844·360×640에서 설명 없이 10초 안에 첫 시설을 선택한다.
2. 13계정 중 지정 계정으로 두 번 이내 선택 입력으로 도달한다. 카메라 조작을 요구하지 않는다.
3. 시설 선택 후 세계가 최소55% 남고 선택 대상이 트레이에 가리지 않는다. 17표찰 겹침 재배치를 합격 근거로 쓰지 않는다.
4. 팬·핀치를 20회 한 뒤 오선택·원치 않는 실제 명령이 0회다. 모든 테스트 명령은 격리 fixture로 검증한다.
5. 명령 접수만 된 상태에서 재고·실적·성공 배지가 바뀌지 않는다. 다음 관측이 없으면 대기/미확인을 유지한다.
6. 연결 끊김에서 운송·생산 애니메이션이 계속되어 정상 가동으로 오해되면 반려한다.
7. 단지·지구·시설·재고·일정·운영 기록·복구7종 상태를 확인한다. 조회 또는 편집이 이전보다 막히면 반려한다.
8. 평면 카드·메뉴·숫자를 읽고 3D를 누르지 않아도 모든 주 작업이 끝나는 구조라면 핵심 방향 미달이다. 첫 조작과 결과의 귀착점은 세계여야 한다.
9. '다음 시설도 확인하고 싶다'는 동기가 3분 안에 생기는지 실제 사용으로 관찰한다. 관찰 없이 재미·장기 몰입 합격을 주장하지 않는다.
10. 기존 모바일 실물과 같은 기기 폭으로 나란히 놓았을 때 건물 크기·세계 비중·터치 흐름이 명백히 바뀌지 않으면 재작업한다.

현재 문서는 설계와 공식 정지 이미지 대조의 증거다. 구현·프레임 성능·실기기 발열·게이머 실제 플레이 결과는 여기서 완료로 판정하지 않는다. 다음 담당: `kh_team_game_build` 구현, `kh_team_game_verify` 격리 실행, `kh_team_playtest_qa` 최종 재미·조작 판정.
