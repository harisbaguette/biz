# 세로 모바일 게임 관점 검수

2026-10-22 · 독립 검수 범위: 390×844·360×640의 실제 headless Chromium 터치 플레이. 운영 API는 전부 fixture로 격리했다. 실제 업무 지시는 보내지 않았다.

## 판정

**검증한 세로 모바일 게임 조작·화면 구조는 합격이다.** 실제 시설 선택·명령 접수·후속 관측까지 세계 안에서 연결된다. 장기 재미와 실기기 성능은 별도 관찰이 남는다.

건물 자체를 누르면 카메라가 다가오고, 같은 세계 위에서 재고·일정·재확인·제작 운영으로 이어진다. 기존의 17표찰 목록을 축소한 형태는 벗어났다. 다만 표찰 클릭 성공만으로 게임 조작 합격을 내릴 수 없으므로 실제 Canvas 건물 터치까지 별도로 검사했다.

숨긴 원본 모델의 ray 간섭 가능성은 잠재 결함으로 따로 처리됐다. 실제 보이는 주 건물 표면을 우선하고 전용 보조 hit target으로 보완한다. 숨긴 소품이 위 오선택의 직접 원인이었다고 단정하지 않는다.

검수 도중 추가된 가짜 코인·경험치·완료 애니메이션 요구는 없다. 문제 해결을 위해 실제 사업 데이터의 의미를 바꾸지 않는다.

## 남는 한계

- 상용 모바일 게임 수준의 장기 몰입, 실제 엄지 감각, GPU 발열·배터리는 headless 검증으로 판정할 수 없다.
- 평면 목록·입력 폼은 긴 재고·일정·운영 기록의 상세 도구로 남는다. 주 흐름은 세계와 현장 트레이지만, 모든 문서 편집을 3D 오브젝트 조작으로 바꾼 것은 아니다.
- 실제 제작·제출에는 원본 작업기와 계정 인증의 제약이 있다. 모바일에서 지시가 접수돼도 즉시 실행 또는 로그인 복구로 표현하지 않는다.
- 세계의 팔레트·건물·도로가 일관된 모바일 장면으로 개선됐다는 것과 AAA급 전용 아트 제작은 다르다. 현장 조작과 실제 운영 판단을 기준으로 검수했다.
