# 설비 움직임과 실제 상태

생산·검수 구역에서 왼쪽 프레스는 생산, 오른쪽 로봇팔은 제작 검수를 나타낸다. 프레스 왕복은 Kenney 원본 clip, 로봇팔의 집기·선회·복귀는 원본 관절에 추가한 clip이다. 파일·출처·가공 내용은 `ASSETS.md`에 있다.

| 보이는 동작 | 근거 | 멈추는 조건 |
|---|---|---|
| 프레스 왕복과 출구 롤러 회전 | 새 생산 관측이 `working`·`generating`·`reviewing` | 생산 정지, 대기·오류, 30분 넘은 lane 관측, 연결 미확인 |
| 검수 로봇팔의 관절·집게 | 제작 검수 또는 메타데이터 작업의 실행 관측 | 제작 정지, 검수 대기·오류, 오래된 관측, 연결 미확인 |
| 계정으로 작품 운반 | 실제 새 재고 증가 | 새로운 증가가 없으면 출발하지 않음 |
| 제출·공개 작품 이동 | 새 제출 사건 또는 제출→승인·공개 전환 | 과거 사건은 재생하지 않으며 제출 막힘에서 출발하지 않음 |

움직임은 가동 여부를 나타낸다. 반복 횟수가 생산 개수·심사 진행률·예상 완료 시간을 뜻하지 않는다. 외부 심사 대기만으로 로봇팔을 돌리지 않는다. 계정 시계는 실제 다음 확인 시각을 유지한다.

`자동화 설정 → 움직임 줄이기`에서는 설비와 운반을 멈추고 상태 문구·표시등은 유지한다. 숨겨진 탭에서도 재생을 멈추며 돌아왔을 때 지난 시간을 몰아 재생하지 않는다. 표시등은 가동 청록, 대기 황색, 오류 적색, 정지·연결 미확인 회색이다.

두 animated GLB의 전체 움직임 범위를 기준으로 크기와 배치를 정한다. 움직이는 노드는 정적 병합·인스턴싱에서 제외하고 `AnimationMixer`로 재생한다. 렌더는 최대 30fps, 그림자 갱신은 약 120ms 간격이며 화면 재생성 시 mixer·GPU 자원을 해제한다. 파일이나 필요한 clip이 없으면 기존 다시 받기 버튼으로 복구한다.

검증 명령: `BIZ_TEST_OWNER_CYCLE_FIXTURE=synthetic BIZ_TEST_ORIGIN=http://127.0.0.1:4363 npx playwright test tests/industrial-motion.e2e.ts tests/owner-motion.e2e.ts`. 데이터 쓰기는 격리된 메모리 DB에서만 수행한다. Chromium·WebKit의 실제 관절 변위, 정지, 복귀, 재시도와 다섯 화면 크기를 검사한다. 결과는 `artifacts/animated-industry/`에 보관한다. 실기기 발열·배터리 검증은 별도다.
