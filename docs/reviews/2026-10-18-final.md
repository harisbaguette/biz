## 실제로 바뀐 것

- 중복 수치 띠·공정 바·장식과 상시 도구를 덜었다. 최근 변화·확인할 일·선택 대상에 정보를 모았다.
- 제작 라인·검수 게이트·목표 비축랙·출하 도크를 각기 다른 시설로 만들었다. 13계정은 실제 제작물로 구별하며 실제 재고가 목표 대비 적재량으로 보인다.
- 연결 상태와 업로더 실행을 구별한다. 실행 잠금만으로 성공이나 진행을 단정하지 않으며 오래된 관측은 확인 필요로 표시한다.
- 지시의 접수→반영→후속 관측, 실패 예약의 사유→재예약→기록 보존을 같은 업무 맥락에서 처리한다. 제출 자격 없는 재고를 제출 가능으로 표시하지 않는다.
- 가로 폰 메뉴 잘림·세로 PC 대상 누락·명패 겹침·확대 무반응을 해결했다. 3D 로딩 실패와 GPU 오류에서도 관리 경로와 재시도가 남는다.
- Safari의 실패 모듈 캐시와 배포 버전 혼합을 처리했다. 스냅샷 파손 후 복구, 미리보기 실패의 유한 재시도, 오래 대기한 지시 누락도 고쳤다.

최종 통합 시험은 **Chromium 19/19, WebKit 19/19**, API·데이터·운영 서버 **34/34**, 격리 연결 프로그램 **8/8**이다. 원본에 시험 제출·정지·재확인 지시를 보내지 않았다. 자세한 범위와 원본 기록은 [검증 기록](../검증.md)에 있다.

## 남은 것

Cloudflare 로그인 상태가 해제돼 Worker/D1 생성, biz.bluekite.co.kr 적용, 외부 HTTPS 확인과 상시 연결 서비스 등록은 하지 못했다. 배포 권한은 이미 사용자에게 받았으며 재허가가 필요한 상황은 아니다. 계정 인증이 복구되면 [배포 안내](../DEPLOY.md)의 적용·검증을 이어간다.

실제 휴대전화·태블릿 성능과 장기 재방문 재미는 미측정이다. 고객 심사도 운영 사용성까지만 승인했다. 다른 사업의 데이터 연동과 개별 재고 제외 사유의 세분화는 후속 범위이며 이번에 구현한 것으로 주장하지 않는다.
