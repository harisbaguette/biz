# 7개 전문 분야 독립 혹평 — 종합 결과

**판정: 현재 결과물은 요청한 완성도에 미달한다.** 특히 3D 조작과 운영 상태의 신뢰성에 실제 결함이 있고, 사업 흐름을 공간에서 읽고 다음 행동을 결정하는 설계가 부족하다. 상용 산업·경영 게임 수준의 관제로 완성됐다고 판단할 수 없다.

2026-10-18의 실행 중 빌드와 소스를 대상으로 UX, UI·시각 품질, 게임 플레이, Three.js 기술, 기능·오류, 고객 관점, 목적 부합 전문가를 실제 호출했다. 각자 먼저 검토한 뒤 겹치는 재현 근거를 공유했다. 아래는 중복을 합친 우선순위이며, 개별 보고서에 나머지 지적과 파일 위치·재현 절차·수정 후 합격 기준을 보존했다.

## 가장 큰 설계 문제

저폴리 스타일이나 무료 에셋이라는 이유로 반려한 것이 아니다. 모델의 가격·개수는 조작, 정보의 의미, 장면 구성의 완성도를 보증하지 않는다. 현재 크림·청록 색상과 한글 서체를 전부 바꿀 근거도 없다.

## 그 밖에 남은 지적

- **탐색·판단:** 재고 검색/필터 초기화, 로그인 선행 조치의 늦은 안내, ‘심사 중’ 숫자가 그림 목록 대신 일정으로 이동, 실제 다음 제출일과 마지막 한도 관측 시각의 미노출. ‘출하 일정’은 현재 메모·재확인 예약이며 실제 제출 시각을 예약하는 기능과 다르다.
- **조작·가독성:** 모바일 토스트가 약 5초간 주 행동을 가리고 클릭을 가로챔, 작은 버튼과 낮은 텍스트 대비, 번호판 위에서 시작한 지도 드래그 차단, 두 손가락/오른쪽 버튼을 계정 선택으로 오인하는 입력 경로.
- **데이터·복구:** 원본의 수동 확인 필요 상태 3개 누락, 스냅샷 갱신과 조회가 엇갈릴 때 계정 요약과 재고 버전 혼합, 로컬 SQLite 동시 batch 충돌, 포화된 큐에서 같은 요청 ID 재시도 429, 최신순이 아닌 ‘최근 제작물’. 각 재현의 적용 환경은 기능 보고서에 구분했다.
- **시각 마감:** 시설·도로·배경의 약한 명도 위계, 큰 운하 평면과 업무에 연결되지 않은 장식의 비중, 중복 HUD, 회전과 맞지 않는 방향 안내. 전체·근접·모바일의 기준작 대조가 필요하다.

## 수정 순서와 합격 기준

1. **입력과 상태를 먼저 믿을 수 있게 한다.** 카메라 갱신·라벨 위치/충돌·화면 잘림·청크 실패 격리·eligible 라벨·업로더 생존 판단을 수정한다. 여섯 화면 크기에서 13계정이 보이고, 어느 표식을 눌러도 같은 계정이 선택돼야 한다. 정지 장면에서도 확대·회전 전후의 실제 픽셀이 바뀌고 라벨이 시설에 붙어 있어야 한다.
2. **운영 과업을 끝까지 이어 준다.** 전체/계정 일정 범위, 신규 일정 가시성, 지시의 대기/실패/관측 결과, 로그인 등 선행 조치, 재시도와 검색 맥락을 정리한다. ‘문제 찾기 → 이유 이해 → 조치 → 결과 확인’과 ‘다음 제출·재고 확인’이 원본 화면을 다시 뒤져야만 끝나는 구조인지 검증한다.
3. **사업 흐름을 읽는 3D로 다시 설계한다.** 핵심 공정·재고·심사 한도·정체를 시설과 연결하고, 지난 확인 이후 실제 변화를 짧게 보인다. 정상·부족·막힘·복구의 fixture가 공간에서 구별돼야 한다. 가짜 생산·운송·수익·점수는 추가하지 않는다.
4. **남는 UI를 줄이고 마감한다.** 중복 수치/진입을 덜어낸 뒤 명칭, 대비, 터치 영역, 재료와 조명을 맞춘다. 공간의 의미와 조작을 먼저 정해야 장면 마감이 낭비되지 않는다.
5. **실제 운영 조건을 확인한다.** 별도로 남은 Cloudflare 계정 인증 후 도메인·상시 연결을 적용하고 실제 HTTPS를 확인한다. 물리 휴대전화·태블릿의 성능·발열·장시간 복귀와 재방문 효과는 현재 근거로 확인됐다고 할 수 없다.
