## 재심 중 발견한 회귀의 처리

수정 중 캡처에서는 768px·900px·가로 폰의 `상태 수신`이 한 글자씩 줄바꿈됐다. 최종 독립 실행에서는 해당 문구의 렌더 높이가 모두 **14px 한 줄**이며 너비44.47px다. 540px 이하에서는 문구를 숨기고 연결 아이콘·전역 연결 경고로 상태를 전달하는 기존 방식이다.

가로 폰의 중간 수정본은 충돌 회피 때문에 번호가 건물에서 멀리 흩어지고 연결선이 교차했다. 최종 844×390은 실제 시설3행을 함께 배치하고 정면에 가까운 카메라를 사용해 각 표식이 모형 전면에 대응한다. 정상 표식도 많이 이동하면 선별 연결선을 복원한다. 최종 실물에서 이전의 지도 밖 표식·그물 연결선은 나타나지 않았다. 고객 심사자도 같은 최종6뷰에서 이 지적을 철회했다.
