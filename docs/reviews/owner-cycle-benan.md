### O-B03 🔴 해결 · 정지 직전 실행 감지가 미래 자동 확인을 살린다

`src/owner-cycle.ts:107`의 정지 처리에 `!account.running`이 있어, 현재 작업 감지가 남은 채 자동화를 정지하면 다음 자동 확인도 유지된다. `running=true`, `automation.enabled=false`, 미래 `nextCheckAt`을 함께 넣은 순수 입력 1개 중 1개에서 아래 결과를 확인했다.

```text
overviewLabel: 실행 확인 중
nextKind: review-check
nextLabel: 확인 내일 09:30
detail: … 계정 확인 예정이며 제출 시각이 아닙니다. 자동 제출이 정지되어 있어 예정된 계정 순회도 진행하지 않습니다.
```

현재 작업을 감지한다는 것과 다음 순회가 진행된다는 것은 다르다. 현재 실행 감지는 남기되, 정지 상태에서는 실제 요청 예약(`nextKind=request`) 이외의 미래 자동 확인을 약속하지 않아야 한다.

| 수정 후 입력 | overviewLabel | 다음 행동 |
|---|---|---|
| 정지 + 현재 실행 + 내일 자동 확인 | 실행 확인 중 | 재개 필요 · nextAt=null |
