## F01 실행 감지의 한계와 경계

`src/data.ts:70`은 실행 잠금, 관측 시각, 다음 순회를 구분한다. `src/App.tsx:99`가 수신 스냅샷을 정규화해 저장하며 `src/App.tsx:192`에서 업로더 확인 필요를 상위 경고 수에 포함한다. 실제 React 패널 출력에서도 제출 작업기 경고와 운영 상세의 설명이 나타남을 확인했다.

- 실행 잠금이 최근에 감지되면 `실행 감지`다. 잠금이 실제 진척까지 보장한다는 표현은 쓰지 않는다.
- 자동화가 꺼졌더라도 진행 중 잠금이 있으면 `실행 감지 · 이후 정지`이고, 이미 시작한 작업은 마친 뒤 멈춘다고 설명한다. 현재 작업을 즉시 숨기지 않는다.
- 장시간 잠금이 남고 관측이 오래됐으면 `장시간 실행 · 진행 확인` 경고다. 기본 60분 기준의 59분·61분 양쪽 입력을 직접 확인했다. 이는 `max(계정 간격×2,60분)`의 운영자 주의 기준이며 원본의 실행 제한 시간이나 멈춤을 증명하는 기준이 아니다.
- 관측 시각이 아예 없을 때는 경과 시간을 단정하지 않고 시각 확인 불가로 설명한다.

원본 작업기는 한 계정 작업 도중 주기적인 진행 heartbeat를 보장하지 않으므로 이 UI로 실제 hang·사망·단계 완료를 판정할 수는 없다. 실제 제출·심사 결과는 관측된 업무 기록으로 따로 확인해야 한다.
