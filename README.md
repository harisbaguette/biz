# BLUEKITE 사업 관제

미리캔버스 13개 작업동을 선택해 실제 재고·제출·심사·일정을 관리합니다. 다른 사업은 사업 단지 메뉴에서 등록할 수 있습니다.

## 켜기

[사업 관제 열기](https://biz.bluekite.co.kr)에서 접속 암호를 입력합니다. 암호는 운영 맥의 `~/Library/Application Support/BluekiteBusinessControl/접속 안내.txt`에 있습니다. `관제 시작.command`도 이 주소를 안내하며 브라우저 포커스를 옮기지 않습니다.

- 작업동: 실제 제작물·계정 상태·재고를 봅니다. 선택하면 해결할 일, 마지막 관측과 다음 제출 예정이 나옵니다.
- 재고: 제목·키워드 검색, 제출 가능·제출 제외·심사·공개·보류 구분. 검색과 보고 있던 위치를 유지합니다.
- 일정: 직접 할 일 또는 작업기 재확인을 예약합니다. 원본의 다음 제출 예정과 심사 예상일도 확인합니다. 실패한 예약은 이유를 보고 다시 예약하거나 기록을 닫을 수 있습니다.
- 확인할 일: 계정 오류, 로그인 대기, 작업기 지연, 최근 지시 결과.
- 최근 변화: 실제 상태 변경을 최근 40건까지 봅니다. 확인한 기록을 표시해 다음 방문의 새 변화를 구분합니다.
- 운영: 이미지 제작과 제출·심사 자동화를 각각 켜고 끕니다.
- 운영 계획·보고: 운영 또는 사업 단지 메뉴에서 엽니다. 모든 등록 사업의 계획·보고·결정을 저장하고 진행 상태를 관리합니다. [운영 체계](docs/운영체계.md)

지도에는 제작 → 내부 검수 → 비축 → 제출·심사 시설이 있습니다. 오른쪽 위의 지도 표시와 시점 조절을 펼쳐 재고·심사 레이어, 확대·회전·전체 보기를 사용합니다.

화면은 `hong-designsystem`의 Inkpress UI를 사용합니다. 모바일·태블릿은 세로 화면, PC는 옆 메뉴와 상세 패널에 맞춰 단지를 배치합니다. 다크 모드와 큰 글자 설정을 지원합니다. [프런트엔드 구조](docs/FRONTEND.md) · [UI·Three.js 심사](docs/reviews/redesign-benan.md)

재확인 지시는 기존 계정 순서와 30분 간격을 유지합니다. 이미 실행 중인 제출은 끝난 뒤 다음 지시를 처리합니다. 예약·지시 반영과 실제 플랫폼 제출 성공은 별개입니다. 지시를 내린 계정에서 대기·실패·반영 여부와 그 이후의 계정 확인 시각을 함께 봅니다. 원본 조회가 3분 이상 끊기면 연결 경고와 함께 새 지시를 차단합니다.

작업기의 실행 감지와 단계별 진행은 다릅니다. 마지막 기록 후 1시간(운영 간격이 더 길면 그 두 배)이 지나면 진행 확인을 요청하며, 중단으로 단정하거나 자동 재제출하지 않습니다.

상태는 약 45초마다 전송하고 지시는 8초마다 확인합니다. 다른 사업은 등록만 지원하며, 실제 데이터 연동은 각 사업에 맞는 연결 작업이 필요합니다.

## 개발·검증

소스 저장소: [harisbaguette/biz](https://github.com/harisbaguette/biz). 접속 암호·연결 토큰·원본 데이터·실데이터가 포함된 검사 캡처와 로컬 진행 지도는 Git에 올리지 않습니다.

Node.js 24 이상과 기존 미리캔버스 Python 환경을 사용합니다. 새 PC에서는 `npm ci` 후 원본 연결과 개인 설정을 준비해야 합니다. 현재 PC의 `node_modules`는 NAS 속도 문제를 피하도록 로컬 캐시에 연결되어 있습니다.

```sh
npm run build
npm test
python3 tests/bridge_test.py
npm run test:e2e
```

운영 설정의 `npm start`는 웹 주소를 안내합니다. 로컬 화면 수정은 `npm run api`와 `npm run dev`를 각각 실행합니다. 완성 빌드의 로컬 확인은 `BIZ_LOCAL=1 node server/serve.mjs`를 사용합니다. 운영 연결 프로그램은 LaunchAgent가 실행하므로 중복으로 켜지 않습니다. UI 시험은 메모리 DB에서 실행하므로 운영 지시를 발생시키지 않습니다. WebKit 시험은 `BIZ_BROWSER=webkit npm run test:e2e`입니다.

## 배포 상태

`https://biz.bluekite.co.kr`에 Cloudflare Workers + D1로 배포했습니다. Doweek과 같은 계정의 별도 Worker·DB를 사용합니다. 실제 HTTPS·로그인·인증 차단·13계정 수신·일정 저장과 취소를 확인했습니다. 운영 방법은 [배포 안내](docs/DEPLOY.md)에 있습니다.

맥 로그인 시 연결 프로그램이 켜지도록 등록했고, NAS 접근 권한 승인 후 서비스 재시작·연속 수신·웹의 연결 경고 해제까지 확인했습니다. 임시 연결은 종료했으며 설치 서비스 하나가 실행 중입니다. NAS 연결이 늦어지거나 인터넷이 끊기면 재시도합니다. 맥이 꺼져 있거나 로그인하지 않으면 상태 갱신과 지시 반영은 멈춥니다.

현재 맥의 보안 값·원본 스냅샷·접속 암호는 `~/Library/Application Support/BluekiteBusinessControl`에 저장합니다. 프로젝트의 `.local`은 이 개인 폴더를 가리키며 실제 파일은 NAS 공유 폴더 밖에 있습니다. `dist/`에는 기여자 계정이나 그림을 넣지 않습니다. 접속 암호 준비는 `node scripts/provision.mjs`이며 기존 암호를 덮어쓰지 않습니다.

3D 렌더는 headless 브라우저에서 확인합니다. 실제 휴대전화·태블릿 하드웨어의 GPU와 발열은 별도 미확인입니다. WebGL이 없는 기기는 목록으로 같은 업무를 수행합니다.
