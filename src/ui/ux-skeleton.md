# 수익 금고

할 일: 운영자가 13개 계정 중 선택한 계정의 월 확정 수익을 기록하고 12개월 기록 상태를 파악한다.

단계: 1) 선택한 계정과 올해 장부를 본다. 2) 월을 누른다. 3) 금액을 입력하고 저장한다. 계정·연도 변경은 필요한 때만 한다.

요소:
- 계정·연도 선택: 13개 계정과 과거 연도를 공용 Select로 고른다. 현재 선택 계정·올해를 기본값으로 채워 판단을 줄인다(원리 4·5).
- 12개월 금고: 월 순서로 모두 보여 월을 기억하거나 메뉴를 오가는 비용을 없앤다. 금액과 미기록을 같은 자리에 표시한다(원리 1·4).
- 합계와 기록 월 수: 미기록을 0원으로 오인하는 실수를 막는다. 수동 확정·자동 수집 미연결임을 표시한다(원리 11·16).
- 월 편집: 누른 월 아래 한 열로 금액·선택 메모를 편집하고 저장한다. 월 선택 시 금액에 포커스를 둬 손 이동을 줄인다(원리 9·10).
- 취소·미기록 변경: 실수는 저장 전에 되돌리고, 잘못된 확정 기록은 미기록으로 변경한다(원리 11).
- 오류·재시도: 입력을 유지하며 같은 요청을 다시 저장한다. 충돌 때 최신값을 확인한 뒤 사용자가 저장하도록 한다(원리 12).

주 행동: 월을 눌러 확정 수익을 기록한다. 편집 중에는 기록 저장을 가장 강조한다.

과업 검토: 기본 계정·올해는 판단 0회, 월 선택 1회, 금액 입력 1회, 저장 1회다. 별도 추가 메뉴와 월 선택 Select를 없앴다. 첫 사용자는 금고 아래 월·미기록을 알아보고, 금액칸과 저장 결과로 진행을 안다. 빈 장부·읽기 실패·저장 실패·충돌·취소 시 입력 손실 경로를 막는다.
