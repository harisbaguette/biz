# 수익 금고

할 일: 운영자가 13개 계정 중 선택한 계정의 월 확정 수익을 기록하고 12개월 기록 상태를 파악한다.

단계: 1) 선택한 계정과 올해 장부를 본다. 2) 월을 누른다. 3) 금액을 입력하고 저장한다. 계정·연도 변경은 필요한 때만 한다.

요소:
- 계정·연도 선택: 13개 계정과 과거 연도를 공용 Select로 고른다. 현재 선택 계정·올해를 기본값으로 채워 판단을 줄인다(원리 4·5).
- 12개월 금고: 월 순서로 모두 보여 월을 기억하거나 메뉴를 오가는 비용을 없앤다. 금액과 미기록을 같은 자리에 표시한다(원리 1·4).
- 합계와 기록 월 수: 미기록을 0원으로 오인하는 실수를 막는다. 수동 확정·자동 수집 미연결임을 표시한다(원리 11·16).
- 월 편집: 누른 월 아래 한 열로 금액·선택 메모를 편집하고 저장한다. 월 선택 시 금액에 포커스를 둬 손 이동을 줄인다(원리 9·10).
- 취소·미기록 변경: 실수는 저장 전에 되돌리고, 잘못된 확정 기록은 미기록으로 변경한다(원리 11).
- 오류·재시도: 입력을 유지하며 같은 요청을 다시 저장한다. 충돌 때 최신값을 확인한 뒤 사용자가 저장하도록 한다(원리 12).

주 행동: 월을 눌러 확정 수익을 기록한다. 편집 중에는 기록 저장을 가장 강조한다.

과업 검토: 기본 계정·올해는 판단 0회, 월 선택 1회, 금액 입력 1회, 저장 1회다. 별도 추가 메뉴와 월 선택 Select를 없앴다. 첫 사용자는 금고 아래 월·미기록을 알아보고, 금액칸과 저장 결과로 진행을 안다. 빈 장부·읽기 실패·저장 실패·충돌·취소 시 입력 손실 경로를 막는다.


# 계정의 심사와 다음 할 일

핵심 과업은 심사 중인 계정, 비었지만 다음 확인이 잡힌 계정, 직접 풀어야 하는 막힘을 알아내고 그 계정에서 바로 행동하는 것이다.

- 전경: 13개 계정 구역에 심사 여부와 결과 예상 또는 막힌 원인·확인 시각을 함께 표시한다. 실제 그림과 비어 있는 심사판이 상태를 나타낸다.
- 계정 선택: 심사 상태를 가장 크게 둔다. 그 아래에 다음 제출 조건과 재확인·재시도 시각, 막힘 원인을 둔다. 재고와 승인·공개는 작은 보조 조회다.
- 바로 할 일: 막힘은 복구 방법, 정상 심사는 심사 내역, 확인할 일정은 해당 계정의 다음 일정으로 이어진다. 재확인 요청과 원본 플랫폼 완료는 구별한다.
- 다음 일정: 자동 확인·재시도, 수동 제출 계획, 재확인 요청 예약, 직접 처리 메모를 나눈다. 현재 실행기가 수락하는 제출 예약 기능은 없으므로 메모나 재확인 요청을 제출 예약으로 표시하지 않는다.
- 이력: 실제 제출·심사 기록을 먼저 보여 주고, 제작을 포함한 실행 내역은 그 안에서 펼친다.
- 보조 탐색: 하단의 목적지는 전체 보기, 다음 일정, 제출·심사 이력, 자동화 설정이다. 계정 목록과 사업 계획·보고는 설정에서 찾을 수 있다.

수용 기준: 빈 심사함을 선택하면 과거 심사 완료 예상일을 현재처럼 보여 주지 않는다. 심사 중이면서 막힌 계정도 두 상태를 모두 보여 준다. 날짜를 지났다는 이유로 승인이나 제출을 완료 처리하지 않는다. 계정·장부의 선택 맥락과 키보드 초점을 보존한다. 360px·큰 글자에서 주 행동과 오류 복구를 실제로 쓸 수 있어야 한다.

수동 제출 계획이 있으면 막힘·실행 중·자동화 정지와 다음 확인을 그대로 두고 별도의 짧은 날짜 행에 실행 예약이 아님을 명시한다. 다음 일정은 기존 제출 계획 행에서 한 번만 표시한다. 계획이 없는 계정에는 이 행을 만들지 않는다.


다음 일정의 첫 정보는 실제로 잡힌 자동 확인·재시도 시각이다. 다음 제출 계획은 기록이 있을 때만 그 뒤에 보여 주며, 없는 계획을 큰 빈 카드로 강조하지 않는다. 제출 조건은 계정의 다음 확인 행에서 읽는다. 주 행동은 재확인 예약이고 새 입력은 재확인 요청을 기본으로 한다. 직접 처리할 메모는 같은 입력의 종류 선택으로 남긴다. 제출을 실행하지 않는다는 안내는 해당 입력을 저장하는 자리에서 보여 준다.

선택 계정 창은 세계의 청록·아이보리에 연결된 금속 장비 패널로 마감한다. 짙은 프레임과 상태 경고등, 매입된 심사 상태판, 눌리는 깊이가 있는 공용 버튼으로 상태·시각·다음 행동을 구별한다. 장부 본문은 밝게 유지한다.
